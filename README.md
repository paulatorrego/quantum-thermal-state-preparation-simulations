# Quantum Thermal State Preparation — Original TFM Implementation

This repository contains the original simulation code developed for my
Master's Thesis on quantum thermal state preparation.

The project investigates the preparation of quantum thermal states using
a repeated-interaction protocol with a resettable bath.

The simulations include:
- Different notebooks of Hamiltonian models
- General functions (tfm_shared)
- Specific functions of each model

## Thesis

Master's Thesis in Quantum Computing 
Universidad Autónoma de Madrid & Instituto de Física Teórica

## Note

This repository contains the original thesis implementation.
A subsequent refactoring is being developed to transform the codebase
into a modular and reusable simulation framework.
